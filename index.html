前后端结构说明

这部分用于演示“网页为什么能连后端”和“每一层各自做什么”。

前端

  • 使用 `HTML` 搭建页面结构。
  • 使用 `CSS` 控制样式、布局和视觉展示。
  • 使用 `JavaScript` 通过 `fetch` 调用后端接口。
  • 把接口返回的项目数据渲染成卡片、表格和时间线。

接口层

  • 接收前端请求，例如 `/api/overview`。
  • 统一返回 JSON 数据，供前端渲染。
  • 后续可以继续接数据库、算法服务、登录系统。

后端

  • 可使用 `Node.js + Express` 搭建。
  • 负责业务逻辑、数据处理、权限控制和跨域配置。
  • 可部署到 `Render`、`Railway`、`Vercel Serverless` 等平台。
